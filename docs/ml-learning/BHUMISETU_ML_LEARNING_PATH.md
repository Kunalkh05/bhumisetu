# BHUMISETU AI/ML Learning Roadmap & Curriculum

Welcome to the internal engineering & scientific education track for the **BHUMISETU Survival Machine Learning Pipeline**.

This curriculum is designed to take an engineer with basic Python knowledge and guide them step-by-step to a complete, deep, mathematical and architectural mastery of survival analysis, statistical inference, data governance, and production ML systems.
